### G.1 C0 removable singularity (0/0) — [LEM] relative to (E)
Ψ(p) = cos(2π(p²−p−1/16)) / cos(2πp) has 0/0 at p0 ∈ {1/4, 3/4}. Put h = p − p0, s = −1 (p0=1/4), s = +1 (p0=3/4), sinc x = sin x / x (sinc 0 = 1).

**Lemma G1 (sinc rewrite).** For 0 < |h| < 1/2: Ψ(p0+h) = (1+2sh)/2 · sinc(πh(1+2sh)) / sinc(2πh), and the right side is analytic at h = 0 with value 1/2, which is the continuous extension of Ψ.
*Proof.* p0=3/4: p²−p−1/16 = −1/4 + h/2 + h², so numerator = cos(−π/2 + πh(1+2h)) = sin(πh(1+2h)); denominator cos(3π/2+2πh) = sin 2πh.
p0=1/4: p²−p−1/16 = −1/4 − h/2 + h², numerator = sin(−πh(1−2h)) = −sin(πh(1−2h)); denominator = cos(π/2+2πh) = −sin 2πh.
In both cases Ψ = sin(πh(1+2sh))/sin(2πh) = [πh(1+2sh) sinc(πh(1+2sh))]/[2πh sinc(2πh)]; cancel πh ≠ 0. sinc is entire, and for |h| < 0.01, sinc(2πh) ≥ 1 − (2π·0.01)²/6 > 0.999 > 0, so the quotient is analytic there; at h=0 it equals 1/2. ∎

**Lemma G2-cut (Dedekind-cut enclosure, Nathan's method).** Let H = [h⁻, h⁺] ⊂ (−0.01, 0.01) be the ball for h (from the t-ball). For x ∈ [−π/2·1.1, π/2·1.1], sinc x = Σ_k (−1)^k x^{2k}/(2k+1)! is alternating with decreasing terms (|x|² < 6), so the partial sums S_{2m−1}(x) ≤ sinc x ≤ S_{2m}(x) are proven lower/upper bounds (rational/ball arithmetic with outward rounding). Composing the interval extensions (numerator factor, two sincs, positive denominator) gives L(H) ≤ Ψ(p0+h) ≤ U(H) for every h ∈ H. Bisecting H = H₁ ∪ H₂ and taking L = min(L(H₁),L(H₂)), U = max(U(H₁),U(H₂)) preserves the inclusion, and the cut (L, U) is tightened until width ≤ the true variation of Ψ over H (|Ψ'(p0)| = 1, so ≈ 2r).
*Proof of containment.* Each interval extension contains the range of its function on its argument interval (inclusion monotonicity of ball arithmetic); the bound S_{2m−1} ≤ sinc ≤ S_{2m} is the alternating-series remainder estimate; division is by an interval contained in (0.999, 1], so it is valid. A union of sub-enclosures contains the range on the union. Hence the true value Ψ(p0+h) lies in the cut for every h in H, in particular at the true t. ∎
Rests on (E): the C implementation matches this description (validated numerically on 182,630 points, v9p/val_psi.py — [NUM], not a proof of the code).

### G.2 N-step (window crossing t_N = 2π(N+1)²) — [LEM] relative to (E)
v9 fixes N = ⌊√(T/2π)⌋ per window and builds F_N(t) = Σ_{n≤N} n^{-1/2} e^{-it log n} by interpolation. For t ≥ t_N the Riemann–Siegel formula needs N'(t) = ⌊a(t)⌋ = N + k (k ≥ 1) and p' = a − N' = p − k ∈ [0,1).
**Lemma G2.** For every t, Z(t) = 2 Re(e^{iθ(t)} F_N(t)) + C(t) + R(t), with C(t) = (−1)^{N'−1}(t/2π)^{−1/4}Ψ(p') + 2Σ_{n=N+1}^{N'} n^{−1/2} cos(θ(t) − t log n), and |R| ≤ 0.127 t^{−3/4}.
*Proof.* The RS formula with N' and p' is Z = 2Σ_{n≤N'} n^{−1/2}cos(θ − t log n) + (−1)^{N'−1}(t/2π)^{−1/4}Ψ(p') + R (Gabcke's bound applies since N' = ⌊a⌋). Split Σ_{n≤N'} = Σ_{n≤N} + Σ_{N<n≤N'}; and 2Σ_{n≤N} n^{−1/2}cos(θ − t log n) = 2Re(e^{iθ}F_N). For k = 0 the added sum is empty and the formula is unchanged. ∎
OPEN (G2-a): when the t-ball straddles t_N, k is ambiguous. The formula is then needed for both k-values on the two sub-balls; I did not re-audit whether v9p splits the ball or relies on continuity across t_N. Flagged OPEN until the c0term code is read for that case.

### G.3 Chunked centre-out close-pair resolution — [LEM] relative to (E); search heuristic [HEUR]
**Lemma CP.** Let [a,b] with integers N⁻ ≤ N(a) and N(b) ≤ N⁺ (Turing-method bounds), and S pairwise-disjoint open intervals (x_j, y_j) ⊂ (a,b) with certified Z(x_j)Z(y_j) < 0. If S = N⁺ − N⁻ then every zero of ζ with ordinate in (a,b] is on the critical line and simple, there is exactly one in each interval, and N(b) − N(a) = S.
*Proof.* Each sign change gives an odd-order zero 1/2+iγ, γ in its interval; the intervals are disjoint, so S ≤ N(b) − N(a) ≤ N⁺ − N⁻ = S (N counts all zeros, on or off the line, with multiplicity). Equality forces exactly one zero, of multiplicity 1, in each interval and no other zeros (off-line zeros come in pairs and would add ≥ 2). ∎

**Theorem G3 (chunked splice).** Original run on W gives bounds N⁻, N⁺ and S₀ = N⁺ − N⁻ − d certified brackets B₀ (d = 2 or 4). Pick cuts L < R not interior to any bracket of B₀. Let B₁ = certified brackets of an independent fine run on [L,R], all contained in [L,R]. Spliced set B = {β ∈ B₀ : β ⊄ [L,R]} ∪ B₁. If B is pairwise disjoint (sorted y_j ≤ x_{j+1}) and |B| = N⁺ − N⁻, then W is PROVEN under Lemma CP.
*Proof.* (i) Certification of a sign of Z at a point is a property of Z, not of the run that found it; so every reused bracket in B₀ stays a valid certified sign change (soundness of reuse). (ii) Brackets of B₀ not inside [L,R] lie entirely in W \ (L,R) because L, R are not interior to any bracket; brackets of B₁ lie in [L,R]; disjointness is checked explicitly, and a shared endpoint x has Z(x) ≠ 0 (its sign is certified), so no zero is counted twice. (iii) Apply Lemma CP with the ORIGINAL window bounds N⁻, N⁺. ∎
Remarks. The bisection probes (exact chunk-boundary N values) only *locate* the deficient chunk; soundness uses only N⁻, N⁺ of the full window plus disjoint certified brackets, so a wrong probe can waste compute but cannot produce a false PROVEN. The gate additionally requires the chunk's own Lemma CP bounds to equal the probe values and recovered = d (extra checks). Contiguity: driver requires 0 ≤ N(prev hi) − N⁻ and overlap brackets ≤ ovN ≤ overlap brackets + 1. Distinct-zero totals = N(covered_hi) − N(3e12) from endpoint values, so overlaps are never double counted. The centre-out ordering (Nathan A. Meeks) is a search heuristic [HEUR]; it plays no role in the proof.

### G.5 Independent-check gates for OPEN-1 (G-cut, G-Turing, G-RS) — Nathan A. Meeks & Grok. [NUM]/[LEM] candidate, unrefereed; not RH
Code: `spotcheck/indgates.py` (shares no code with v9/fftzi). Z(t)=Re(e^{iθ(t)}ζ(1/2+it)) in Arb (python-flint 0.9.0, acb zeta + lgamma, 128→256→512-bit (64-bit measured never certifying at t≈3·10¹², dropped 2026-10-30 14:50 MST)), points passed as exact decimals.
- **G-cut (Dedekind cut; method Nathan A. Meeks).** If an endpoint p has an Arb ball containing 0, replace p by the nearest p′=p±10⁻¹²·2ᵏ lying strictly between its neighbours in the sorted endpoint list whose Arb sign is certified. [LEM] Order is preserved, so the brackets stay disjoint and every certified sign change still lies in a distinct sub-interval of [lo,hi]. G-cut fixes signs only; it never supplies a count.
- **G-Turing.** Mesh step 0.05 on [a−h,a+h], h=24, plus search-only refinement at same-sign |Z| dips. With L(t), R(t) the certified sign-change counts to the right/left of a and Trudgian's bound |∫_{t1}^{t2}S| ≤ 2.067+0.059 log t2 (Math. Comp. 80 (2011) 2259–2279), N(t)=θ(t)/π+1+S(t) gives
  (∫_{a-h}^{a}(θ/π+1) + ∫R − B(a))/h ≤ N(a) ≤ (B(a+h) + ∫_a^{a+h}(θ/π+1) − ∫L)/h, with ∫θ from the Stirling antiderivative plus a 1/t³ remainder ball. [LEM] If both bounds round to the same integer, N(a) is that integer. Missed zeros only loosen the bounds, so the search never affects soundness.
- **G-RS.** Every bracket endpoint of the block is evaluated by the independent Z (G-cut on any uncertain one). Substitution, stated plainly: Z is computed from Arb's rigorous ζ enclosure, not from a Riemann–Siegel main sum with Gabcke's remainder. A pure RS sum has about 6.9·10⁵ terms at t≈3·10¹², which is roughly 10× slower in python-flint. **OPEN-1b: RESOLVED (Oct 30, 2026; Nathan A. Meeks & Grok).** RS+Gabcke is not needed. Argument: (i) Arb computes ζ(s) and Hardy Z(t) (acb_dirichlet_zeta, acb_dirichlet_hardy_z) in midpoint–radius ball arithmetic; every output ball is guaranteed to contain the true value, with all truncation (Euler–Maclaurin / Riemann–Siegel-type internal algorithms) and rounding errors bounded rigorously — F. Johansson, "Arb: efficient arbitrary-precision midpoint-radius interval arithmetic", IEEE Trans. Computers 66(8):1281–1292 (2017); F. Johansson, "Rigorous high-precision computation of the Hurwitz zeta function and its derivatives", Numer. Algorithms 69 (2015) 253–270; Arb/FLINT documentation, acb_dirichlet module (flintlib.org). (ii) Hence a sign of Z certified from an Arb ball not containing 0 is a valid certificate, independent of v9's FFT-interpolation and Gabcke code (no shared code). (iii) Speed: Arb path ~10× faster than a python-flint RS sum (~6.9·10⁵ terms) at t≈3·10¹².
Trust basis / remaining assumptions (stated honestly): (A1) correctness of Arb/FLINT's implementation and of its documented error bounds — published and widely used (e.g. in LMFDB), but NOT formally verified; (A2) correctness of the python-flint bindings and of our glue code (indgates.py) mapping brackets to Arb calls; (A3) G-Turing still relies on Trudgian's published S(t) bound as transcribed in our code. No new OPEN item from G-RS itself; overall OPEN-1 (human referee of v9's own bounds) is unchanged.
- **Rule G5 (resolve rule).** An independent certificate for block [lo,hi] needs all three of the following:
  (i) G-Turing returns exact integers N(lo), N(hi); for a whole window they must equal v9's Na, Nb; for a close-pair chunk block (no v9 N at chunk ends) they are used directly, and the block's bracket count must equal N(hi)−N(lo).
  (ii) G-RS certifies exactly N(hi)−N(lo) disjoint opposite-sign brackets in [lo,hi], with no same-sign (conflicting) bracket.
  (iii) No endpoint is left uncertain after G-cut.
  A certificate needs both a count and enough sign changes, so no single gate is sufficient. G-cut alone and G-RS alone fix signs only; G-Turing alone fixes only the count. Order is by measured cost: G-cut on known-uncertain points first, then G-Turing, then G-RS. The run stops early only on failure: a G-Turing mismatch or ambiguity fails fast, before G-RS runs. Otherwise it stops right after G-RS, the earliest point at which (i)–(iii) can all hold. Any failure → FAILED.md and stop, with no gap skipped. A block that passes is "two independent programs agree"; a human still has to review both codes.
- **Triggers.** A block gets the gates if the close-pair gate fired (block = the spliced chunk [T+L,T+R]; all other triggers use the whole window), v9 reports refine_disagreements>0 (uncertain signs), the overlap check mismatches, or its idx is listed in `ind_blocks.txt` (blocks Nathan names). In-path C0/N-step firings and internal δ escalations are not triggers: they are routine (about 6% of windows). A window PROVEN by the MAXR=200 rung alone is v9-standard (no uncertain sign) and is not a trigger: ~0.3% of windows, and a whole-window G-RS costs ≈40–80 min (≈88k endpoints × 0.17 s / 6 procs), and the gates cost about 18 min per block.

**G.5 trigger rule (Nathan, Oct 30, 2026):** only windows with an error enter the gates: CP short, a remaining uncertain sign, overlap mismatch, or a C0/N-step event (handled by the in-path fix). A v9-PROVEN window, including MAXR-only, gets no gates. A close-pair-repaired window gets independent checks on the repaired chunk only. [NUM] candidate, unrefereed; not RH.

### G.5.t96 Platt fast path (Nathan A. Meeks & Grok) — [NUM], candidate, unrefereed; not RH
**Lemma G5-P.** Let n0=Na−2 and suppose FLINT's `acb_dirichlet_platt_local_hardy_z_zeros` returns balls I_{n0},…,I_{Nb+3}, I_k certified to contain the k-th zero γ_k of Z (multiplicity counted) and no other. If sup I_{Na} < lo < inf I_{Na+1} and sup I_{Nb} < hi < inf I_{Nb+1}, then N(lo)=Na and N(hi)=Nb. If moreover the sorted v9 brackets B_1<…<B_m of [lo,hi] satisfy m=Nb−Na and I_{Na+i} ⊂ int B_i, each B_i contains exactly one zero and the block satisfies Lemma CP independently of v9 and of the Arb path. *Proof.* Labels are certified, so γ_k<lo iff k≤Na, giving N(lo); same at hi. Containment plus disjointness of the B_i and m = count gives a bijection. ∎
References: D. J. Platt, Math. Comp. 86 (2017) 2449–2467; FLINT 3 documentation, acb_dirichlet, "Riemann zeta function zeros (Platt's method)" (flintlib.org/doc/acb_dirichlet.html). Trust: FLINT's implementation (not formally verified), range 1e4≤n≤1e23; heuristic tuning affects only success. On refusal the Arb G-Turing/G-RS path (G.5) is used unchanged. Validated on chunks of 8758, 10202, 27053 (agreement with Arb counts; negative tests refused).

### G.5.t98b Multi-chunk close-pair splice (method: Nathan A. Meeks, centre-out; Nathan A. Meeks & Grok) — [NUM], candidate, unrefereed; not RH
**Lemma G3-M.** Let v9 give certified bounds N(T+A)=N⁻, N(T+B)=N⁺ and certified disjoint brackets B₀ with |B₀| = N⁺−N⁻−d (d = 2 or 4). Take cuts A=c₀<c₁<…<c_m=B that lie inside no bracket of B₀. Each probe chunk [c_j, c_{j+1}] has v9-certified exact N at both ends. Every part with a positive deficit d_j = (N(c_{j+1})−N(c_j)) − #B₀∩[c_j,c_{j+1}] is bisected further, recursively. Each final deficient segment S_k (width ≤ 2·CH) is rerun at δ ≤ 0.02 and must reproduce its own boundary N. Replace B₀∩S_k with the rerun's certified brackets, for every k. Accept only if (i) the result is pairwise disjoint, (ii) the number of recovered brackets equals d, and (iii) the total equals N⁺−N⁻ (Lemma CP on the whole window). Then each bracket holds exactly one zero, and the window is PROVEN.
*Proof sketch.* Theorem G3 applies to each segment separately: brackets outside every S_k are unchanged, certified sign changes. Each S_k has its count fixed by its own certified end values.
